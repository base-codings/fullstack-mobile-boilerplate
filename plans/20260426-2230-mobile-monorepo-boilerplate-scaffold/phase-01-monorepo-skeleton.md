# Phase 01 — Monorepo Skeleton

> Plan: [plan.md](./plan.md) · Brainstorm: [brainstorm-summary.md](./brainstorm-summary.md)

## Overview

- **Priority:** Critical — foundation cho mọi phase sau
- **Status:** completed
- **Description:** Khởi tạo cấu trúc thư mục root + pnpm workspace + Melos + version lock + .gitignore + base configs.

## Key Insights

- pnpm workspace quản lý JS side (apps/api, packages/api-client TS portion nếu có).
- Melos quản lý Dart side (apps/mobile, packages/api-client Dart portion).
- Root `package.json` chứa orchestration scripts (`pnpm bootstrap` chạy cả 2).
- `.fvmrc` lock Flutter SDK; `.nvmrc` lock Node; `.tool-versions` (asdf) optional.
- Volta config trong root `package.json` lock Node + pnpm version per repo.

## Requirements

**Functional:**
- Tạo thư mục: `apps/`, `packages/`, `tools/`, `docs/`, `.github/`
- Khởi tạo workspace files: `pnpm-workspace.yaml`, `melos.yaml`, root `package.json`
- Lock toolchain: `.nvmrc`, `.fvmrc`, Volta block trong package.json
- `.gitignore` đầy đủ cho cả Node + Dart + IDE

**Non-functional:**
- `pnpm bootstrap` (root command) chạy 1 lần xong cả pnpm + melos
- Mỗi command từ root level work được không cần cd

## Implementation Steps

1. **<!-- Red Team #5 -->** Tạo folder structure + commit stub `packages/api_client/` để fresh clone resolve được Flutter path dep TRƯỚC khi codegen chạy lần đầu:
   ```
   mkdir -p apps packages/api_client/lib tools .github/workflows
   ```
   Tạo `packages/api_client/pubspec.yaml`:
   ```yaml
   name: api_client
   description: Generated Dart client for Mobile Boilerplate API. Regenerated by tools/codegen/.
   version: 0.0.0
   publish_to: none
   environment:
     sdk: ">=3.5.0 <4.0.0"
   dependencies:
     dio: ^5.7.0
   ```
   Tạo `packages/api_client/lib/api_client.dart` (placeholder):
   ```dart
   /// Stub. Run `pnpm codegen:api` to generate the real client.
   library api_client;
   ```
   Sau Phase 06 chạy codegen lần đầu, openapi-generator overwrite các file này. Nhưng stub commit từ đầu để `flutter pub get` không fail trên fresh clone.
2. Viết `.nvmrc` lock Node 20 LTS
3. Viết `.fvmrc` lock Flutter 3.27.0 (latest stable Apr 2026)
4. Viết `.gitignore` template (Node, Dart, IDE, OS, env files)
5. Viết `.editorconfig` (utf-8, 2 spaces JS/TS, 2 spaces Dart, LF)
6. Viết `pnpm-workspace.yaml`:
   ```yaml
   packages:
     - 'apps/api'
     - 'packages/*'
     - 'tools/*'
   ```
7. Viết `melos.yaml`:
   ```yaml
   name: mobile_boilerplate
   packages:
     - apps/mobile
     - packages/api_client
   command:
     bootstrap:
       runPubGetInParallel: true
   scripts:
     analyze: melos exec -- "fvm dart analyze ."
     test: melos exec -- "fvm flutter test"
     format: melos exec -- "fvm dart format ."
   ```
8. **<!-- Red Team #5 -->** Viết root `package.json` với:
   - `name`, `version`, `private: true`
   - `engines`: `{ node: ">=20", pnpm: ">=9" }`
   - `volta`: `{ node: "20.18.0", pnpm: "9.12.0" }`
   - `scripts`:
     - `bootstrap`: `pnpm install && pnpm codegen:api && melos bootstrap`   # ★ codegen runs BEFORE melos bootstrap so flutter pub get resolves api_client path dep
     - `lint`: `pnpm -r lint && melos run analyze`
     - `test`: `pnpm -r test && melos run test`
     - `format`: `pnpm -r format && melos run format`
     - `codegen:api`: `bash tools/codegen/generate-api-client.sh`
     - `preinstall`: `npx only-allow pnpm`
     - `prepare`: `lefthook install && husky`
   - `devDependencies`: `melos`, `husky`, `lint-staged` (placeholders)
   - **Note:** `pnpm bootstrap` đầu tiên trên fresh clone: codegen yêu cầu Java + Flutter SDK đã installed (prereq). Nếu chưa có, dev chạy `pnpm install` riêng → `pnpm codegen:api` riêng (manually) → `melos bootstrap`. Doc rõ trong README.

## Risk Assessment

| Risk | Mitigation |
|---|---|
| Melos chưa install global | Doc trong README, optional install: `dart pub global activate melos` hoặc dùng `dart run melos` |
| pnpm conflict với npm/yarn lockfile | `.gitignore` rõ `package-lock.json`, `yarn.lock`; preinstall script: `npx only-allow pnpm` |
| Volta không có sẵn | Optional, chỉ enforce khi dev có Volta; fallback `engines` trong package.json |

## Security Considerations

- `.gitignore` MUST chứa `.env`, `.env.*`, `*.key`, `*.pem`, build artifacts
- Root `package.json` không chứa scripts execute remote URL
